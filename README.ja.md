# FarClock（時差検索）

**Languages:** [English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

[FarClock](https://farclock.com) の公式フィードバックリポジトリ——IANA タイムゾーンデータベースに基づく無料の時差・世界時計検索サイトです。

## FarClock とは？

開いて 3 秒で二地点の時差がわかる、精度にこだわった時差サイトです：

- **国・都市の時差検索**——時間ごとの対照表つき
- **サマータイム両対応**——標準時と夏時間を並記し、現在有効な値をハイライト
- **複数タイムゾーンの国も正確に**——アメリカ/カナダ/オーストラリアなどはゾーンごとに回答
- **30分・45分単位のタイムゾーン**——インド +5:30、ネパール +5:45 も分単位で正確に計算
- **通話に最適な時間帯**の提案と**時差からの逆引き**（日本と時差 N 時間の国）
- 簡体字中国語・繁体字中国語・日本語に対応

データソース：IANA タイムゾーンデータベース（tzdata）、ビルド時に自動同期。

ウェブサイト：[https://farclock.com](https://farclock.com)

## このリポジトリの用途

- バグ報告（時差の誤り、サマータイムの誤り、ページの不具合）
- 新しい国・都市・機能のご提案
- 翻訳・ローカライズの問題報告

問題を見つけたらお気軽に issue をどうぞ（重複がないか検索のうえ、ページ URL と端末/ブラウザ情報を添えてください）。
