# FarClock（时差查询）

**Languages:** [English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

[FarClock](https://farclock.com) 的官方反馈仓库——一个基于 IANA 时区数据库的免费时差与世界时间查询站。

## FarClock 是什么？

打开 3 秒就能看懂两地时差，并且把别家忽略的严谨性做全：

- **国家/城市时差查询**——附逐小时对照表
- **夏令时双值**——标准时间与夏令时并列展示，当前生效值高亮
- **多时区国家不给含糊值**——美国/加拿大/澳大利亚/印尼/俄罗斯按时区分行给答案
- **半时区精确计算**——印度 +5:30、尼泊尔 +5:45、缅甸 +6:30 精确到分钟
- **最佳通话时段**推荐与**时差反查**（和中国时差 N 小时的国家）
- 提供简体中文、繁體中文、日本語三种语言

数据来源：IANA 时区数据库（tzdata），构建期自动同步。

网站：[https://farclock.com](https://farclock.com)
