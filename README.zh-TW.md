# FarClock（時差查詢）

**Languages:** [English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

[FarClock](https://farclock.com) 的官方回饋倉庫——基於 IANA 時區資料庫的免費時差與世界時間查詢站。

## FarClock 是什麼？

打開 3 秒就能看懂兩地時差，並把別家忽略的嚴謹性做全：

- **國家/城市時差查詢**——附逐小時對照表
- **夏令時間雙值**——標準時間與夏令時間並列顯示，當前生效值反白
- **多時區國家不給含糊值**——美國/加拿大/澳洲/印尼/俄羅斯按時區分行給答案
- **半時區精確計算**——印度 +5:30、尼泊爾 +5:45、緬甸 +6:30 精確到分鐘
- **最佳通話時段**建議與**時差反查**（和台灣時差 N 小時的國家）
- 提供繁體中文、簡體中文、日本語三種語言

資料來源：IANA 時區資料庫（tzdata），建置期自動同步。

網站：[https://farclock.com](https://farclock.com)

## 本倉庫的用途

- 回報 bug（時差算錯、夏令時間錯誤、頁面異常）
- 建議新增國家/城市/功能
- 回報翻譯或在地化問題

發現問題歡迎開 issue（請先搜尋避免重複，附頁面連結與裝置/瀏覽器資訊）。
