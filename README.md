**Languages:** [English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

Official feedback and issue tracker for [FarClock](https://farclock.com) — a free, precise time-difference and world-clock lookup site built on the IANA Time Zone Database.

## What is FarClock?

FarClock answers "what's the time difference?" in 3 seconds, with rigor most sites skip:

- **Country & city time differences** — with hour-by-hour conversion tables
- **DST-aware answers** — standard and daylight-saving values shown side by side, current one highlighted
- **Multi-timezone countries done right** — the US, Canada, Australia, Indonesia and Russia get per-zone answers, never a single misleading value
- **Half-hour & 45-minute zones** — India (+5:30), Nepal (+5:45), Myanmar (+6:30) computed exactly
- **Best calling-time windows** between any two places
- **Reverse lookup** — which countries are N hours apart from you
- Available in Simplified Chinese, Traditional Chinese and Japanese

Data source: IANA Time Zone Database (tzdata), synced automatically at build time.

Website: [https://farclock.com](https://farclock.com)

## Purpose of This Repository

- Reporting bugs (wrong time difference, DST errors, broken pages)
- Suggesting new countries, cities or features
- Reporting translation or localization issues
- Sharing usability feedback

If you find something broken, confusing, or missing, please open an issue.
